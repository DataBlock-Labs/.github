# DataBlock Labs

We build data infrastructure and the products that sit on it.

| Project | What it is |
|---|---|
| **[DataBolt](https://www.databolt.dev)** | Competitive data engineering platform: challenges, real datasets, and a video learning series |
| **[Data-Citizen](https://data-citizen.vercel.app)** | Agentic overlay on NYC Open Data |

## DataBolt repositories

| Repo | What it holds |
|---|---|
| `DataBolt.dev` (private) | The platform: web app, Studio, learning, competitions, Rust engine, customer-cloud tier (`platform/`) |
| `databolt-design` (private) | Design system and brand assets: tokens, logo, icons, generated CSS/Tailwind/TS/Swift |
| **[databolt-patterns](https://github.com/DataBlock-Labs/databolt-patterns)** | Open-source ingestion patterns (`databolt.ingestion.api`), Apache-2.0 |
| `databolt-video-studio` (private) | Video studio: Manim + Remotion lessons, voice-over, captions, publishing to the site |
